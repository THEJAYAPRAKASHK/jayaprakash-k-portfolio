# Assets folder guide

Place your real files here using these exact names (or update the paths in index.html if you rename them):

- assets/profile-photo.jpg          -> your hero profile photo
- assets/resume/Jayaprakash-K-Resume.pdf -> your resume PDF
- assets/certificates/certificate-1.jpg, certificate-2.jpg, ... -> certificate images
- assets/gallery/photo-1.jpg, photo-2.jpg, photo-3.jpg, ... -> gallery photos

Until real files are added, the site shows elegant placeholder tiles automatically (no broken image icons).
